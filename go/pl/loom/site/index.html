Why Loom

为软件工程任务而生

不是聊天机器人，而是能在真实仓库里完成工作的 Agent：读代码、改文件、跑命令、验证结果。

交互式 TUI

流式输出、工具调用块、diff 预览、审批弹窗、会话恢复与历史浏览，基于 Bubble Tea 的沉浸式终端体验。

Headless 模式

loom run 单次执行，最终回答写 stdout、诊断写 stderr；非 TTY 下审批自动拒绝（fail-closed），适合管道与脚本。

Web UI

loom serve 启动 HTTP/SSE 服务，浏览器中管理会话、查看流式事件与工具调用，团队远程协作。

桌面版

基于 Wails 的原生 macOS 应用（Apple Silicon / Intel），开箱即用的图形界面，无需接触终端。

事件溯源会话

所有会话事件与检查点持久化于 SQLite，支持崩溃恢复、跨进程 resume、完整历史回放。

安全基座

工作区路径边界、命令沙箱（macOS sandbox-exec/Seatbelt）、环境变量白名单、R0–R4 风险分级与交互审批。

丰富的内置工具

read_file / edit / write / run_cmd / exec_session / git_diff / lint / web_fetch / kb_search / kb_read / update_goal / update_plan …

Skills 扩展

从工作区与用户目录发现 SKILL.md 技能，清单注入系统提示词，正文按需渐进披露。

上下文工程

上下文窗口占用感知、自动压缩（掩码 + 摘要交接）、预算提醒，长任务不失控。

可观测性

OpenTelemetry / Langfuse 追踪（默认关闭），Context Manifest 审计每次模型请求的上下文构成。

MCP 生态

原生 MCP 客户端，直接接入第三方 MCP Server（playwright、filesystem、github…），工具能力随生态扩展。

子代理并行探索

delegate_task 委派独立子代理：独立上下文与预算、默认只读、深度受限，大型仓库并行调研与独立 Review。

跨会话记忆

分层持久记忆（热 / 温 / 冷 + 滚动摘要），记住你的项目约定与偏好，越用越懂你。

知识库检索

内置 kb_search / kb_read 工具，直连 minisearch 服务（BM25 + 向量混合检索，RRF 融合），chunk 级检索与全文读取，服务故障优雅降级。

检查点回退

事件溯源 + 检查点：任意时刻回滚或分支，撤销错误改动，对比历史快照。

Model-Agnostic

一个 Agent Harness，
任意模型端点

模型无关的消息/工具协议，内置 OpenAI 与 Anthropic 两种 provider。在 ~/.loom/config.yaml 中用 type 选择协议栈、base_url 切换 API 提供商、wire_api 切换线协议（chat / responses / messages）。

两分钟上手

CLI 支持 macOS / Linux · 桌面版支持 macOS（Apple Silicon / Intel）· OpenAI 兼容端点与 Anthropic Messages API

1 安装
$ brew tap liubang/loom
$ brew trust liubang/loom # macOS：信任第三方 tap（新版 Homebrew 要求）
$ brew install loom-cli # CLI（macOS / Linux）
2 配置
$ loom # 首次运行：自动生成 ~/.loom/config.yaml 模板
$ $EDITOR ~/.loom/config.yaml # 填入 api_key（或 api_key_env）、base_url、model
3 开始
$ loom # 进入交互式 TUI
$ loom run "修复 ./pkg 下的编译错误" # 单次执行（headless）
$ loom resume <session-id> "继续" # 恢复会话
$ loom serve # 启动 Web UI（浏览器访问）
4 桌面版（macOS）
$ brew install --cask loom-agent # 桌面版（Apple Silicon / Intel），或从官网下载 DMG
5 直接下载（免 Homebrew）
$ curl -sSL https://github.com/liubang/playground/releases/latest/download/loom-darwin-arm64.tar.gz -o loom.tar.gz # macOS arm64；Linux 换 loom-linux-amd64 / loom-linux-arm64
$ tar xzf loom.tar.gz
$ mkdir -p ~/bin && mv loom ~/bin/ # 或 sudo mv loom /usr/local/bin/
$ export PATH="$HOME/bin:$PATH" # 写入 ~/.zshrc / ~/.bashrc 持久生效
Linux 也可用 deb 包：sudo dpkg -i loom_*.deb；macOS 桌面版下载 DMG 拖入 Applications
LOOM_HOME数据根目录（默认 ~/.loom）：配置、会话库、日志、记忆、规则、技能
context_windowconfig.yaml 字段：模型上下文窗口 token 数，驱动自动压缩
LOOM_LANGFUSE_PUBLIC_KEY / SECRET_KEY经 config.yaml 的 public_key_env / secret_key_env 引用的追踪密钥（默认关闭）
knowledge_baseconfig.yaml 字段：base_url / api_key / collections，配置后启用 kb_search / kb_read 知识库工具
